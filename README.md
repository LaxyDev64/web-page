## About

**web-page** is a clean, beginner-friendly web project built with pure HTML, CSS, and JavaScript. It serves as an open template and learning resource — anyone can clone it, modify it, and make it their own.

Whether you're just starting out in web development or looking for a lightweight base to experiment with, this project is for you.

##  Getting Started

### Prerequisites

All you need is a modern web browser. No build tools or dependencies required.

### Running Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/LaxyDev64/web-page.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd web-page
   ```

3. **Open in browser**
   - Double-click `index.html`, or
   - Use a local development server (e.g. [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for VS Code)
